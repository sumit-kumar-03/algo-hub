# Elements of Programming Interviews in Python

Practice problems from *Elements of Programming Interviews in Python* (Aziz, Lee, Prakash), limited to the book's study plan (Table 1.2).

**217 book problems and variants, 167 extra practice variants.**

## Layout

```
elements_of_programming_interviews/
  <NN>_<chapter>/
    <X.Y>_<section>/
      <problem>.py            # main problem from the book
      variant_<problem>.py    # book variants, plus extra practice variants (C0/C1 sections)
```

Each `.py` file is standalone: the problem statement in the module docstring, a `Solution` (or named) class with `# TODO` stubs, and a `test_*()` suite that runs on execution:

```bash
python3 elements_of_programming_interviews/04_primitive_types/4.7_compute_x_power_y/power_x_y.py
python3 run_tests.py elements_of_programming_interviews/05_arrays     # from the repo root: progress for a chapter
```

Chapter 20 problems are design discussions, so each is a `.md` prompt with questions to clarify and an answer template.

### Extra practice variants

Every C0 and C1 section has extra practice variants beyond the book (at least 5 variants per section), graded from warm-up to stretch. Their docstrings start with `EPI X.Y Extra Variant` and say which technique they build on. Difficulty: 🟢 Easy, 🟡 Medium, 🔴 Hard.
